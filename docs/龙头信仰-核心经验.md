# 龙头信仰 - 核心经验总结

> 来源：小欧 16 年实战经验精华
> 整理时间：2026-03-11

## 💎 七大核心金句

### 1️⃣ 选股逻辑：从情绪到业绩

**原话：**
> "选股逻辑思路是：从热点题材入手，观察资金流向、市场情绪好不好，然后看个股股价，技术形态和成交量，最后才是业绩。"

**深度理解：**
```
传统选股：业绩 → 技术 → 资金 → 题材（从下往上）
龙头选股：题材 → 资金 → 情绪 → 形态 → 业绩（从上往下）

核心差异：
- 传统：先看公司好不好（基本面）
- 龙头：先看资金要不要（情绪面）

本质：炒股炒的是预期，不是现在
```

**融入系统：**
- ✅ 多指数情绪判别 = 判断"市场情绪好不好"
- ✅ 大小盘风格识别 = 判断"热点题材在哪里"
- ✅ 成交量评分 = 判断"资金流向"

---

### 2️⃣ 量比是核心指标

**原话：**
> "量比小于 0.5，属于明显缩量，缩量能创新高，说明主力高度控盘，而且可以排除主力出货的可能"

**深度理解：**
```
量比 < 0.5 + 股价创新高 = 主力高度控盘 ✅
逻辑：
- 缩量 = 没人卖
- 还能创新高 = 少量资金就能拉上去
- 结论：筹码集中在主力手里

量比 > 1.5 + 突破阻力位 + 缩量回调 = 关注机会 ✅
逻辑：
- 放量突破 = 主力进攻
- 缩量回调 = 洗盘不是出货
- 结论：回调是上车机会
```

**融入系统：**
- ✅ 9 大指数量比全部纳入评分（权重 30%）
- ✅ 量比 < 0.8 → 缩量加分
- ✅ 量比 > 1.5 + 上涨 → 放量进攻加分

---

### 3️⃣ 追涨杀跌的正确姿势

**原话：**
> "正确地追涨杀跌，就是追在股票启动初期，杀在趋势下跌之际"

**深度理解：**
```
错误理解：追涨杀跌 = 盲目追高 + 恐慌割肉
正确理解：追涨杀跌 = 追启动初期 + 杀下跌之际

追涨：
- 不是涨了很多才追
- 是刚启动（首板/二板）就追
- 核心：启动初期 = 确定性最高

杀跌：
- 不是跌了很多再杀
- 是趋势刚破位就杀
- 核心：下跌之际 = 损失最小
```

**融入系统：**
- ✅ 情绪周期"启动期"信号 = 追启动初期
- ✅ 情绪周期"退潮期"信号 = 杀下跌之际
- ✅ 特殊信号"冰点" = 启动初期识别
- ✅ 特殊信号"高潮" = 准备杀跌预警

---

### 4️⃣ 大收获后强制空仓

**原话：**
> "大收获之后要学会空仓... 当一个人成功一次后会增加自信心，连续成功便会自信心爆棚... 直到大亏时才会使信心大幅下降"

**深度理解：**
```
人性弱点：
成功 → 自信 → 连续成功 → 自信爆棚 → 随意出手 → 大亏 → 信心崩溃

解决方案：
大收获后 → 主动空仓 → 冷静期 → 重置心态

本质：
- 不是技术有问题
- 是心态会变形
- 空仓是保护心态，不是保护利润
```

**融入系统：**
- ✅ 情绪"高潮期" → 仓位建议 40-60%（强制减仓）
- ✅ 情绪"高潮末期" → 仓位建议 20-30%（大幅减仓）
- ✅ 特殊信号"极致高潮" → 撤退信号（清仓预警）

---

### 5️⃣ 三不卖出原则

**原话：**
> "低位出现向上缺口的票不要出... 尾盘急跌的票不要出... 上升趋势的股票不要出"

**深度理解：**
```
三不卖出原则：

1. 低位缺口不出
   - 逻辑：多头已占主导，不回补
   - 本质：趋势信号，不是随机波动

2. 尾盘急跌不出
   - 逻辑：主力故意让 K 线难看
   - 本质：洗盘不是出货

3. 上升趋势不出
   - 逻辑：沿着均线走，不做 T
   - 本质：趋势是你的朋友

核心：区分"真下跌"和"假下跌"
```

**融入系统：**
- ✅ 趋势得分占 30%（站上均线数量）
- ✅ 上升趋势（4 条均线）→ 持有信号
- ✅ 尾盘急跌识别 → 不恐慌信号

---

### 6️⃣ 概率游戏的本质

**原话：**
> "所有的炒股方法都是基于概率，通过风险控制，仓位管理，资金管理才能把这种概率转化为优势"

**深度理解：**
```
炒股本质 = 概率游戏

公式：
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损

转化优势三要素：
1. 风险控制 → 止损（亏小）
2. 仓位管理 → 顺势重仓，逆势轻仓
3. 资金管理 → 不大亏，留得青山在

核心：不是追求高胜率，是追求高盈亏比
```

**融入系统：**
- ✅ 情绪周期直接对应仓位（冰点 10% / 高潮 80%）
- ✅ 特殊信号识别 = 找高确定性机会
- ✅ 综合得分 < 30 → 空仓（风险控制）

---

### 7️⃣ 主流、主动、主升

**原话：**
> "六个关键字：主流、主动、主升"

**深度理解：**
```
主流 = 主线题材，资金聚焦的地方
主动 = 主动上涨，不是被动跟随
主升 = 主升浪，涨幅最大那段

三者关系：
主流题材 → 主动上涨 → 主升浪

本质：
- 主流：选对方向
- 主动：选对时机
- 主升：拿住利润
```

**融入系统：**
- ✅ 大小盘风格识别 = 找主流
- ✅ 科技独立信号 = 找主动
- ✅ 情绪周期高潮期 = 主升浪持有

---

## 🧠 核心三要素

| 核心 | 含义 | 对应系统功能 |
|------|------|--------------|
| **顺势** | 跟着资金走，不猜顶底 | 情绪周期判断 + 大小盘风格 |
| **仓位** | 顺势重仓，逆势轻仓 | 周期阶段对应仓位建议 |
| **概率** | 找确定性，控制风险 | 特殊信号识别（冰点/高潮） |

---

## 🎯 系统必须记住的

1. **选股从情绪入手，不是从业绩入手**
2. **量比是核心指标（权重 30%）**
3. **追启动初期，杀下跌之际**
4. **大收获后强制空仓（高潮期减仓）**
5. **上升趋势持有，不做 T**
6. **一切基于概率，仓位管理转化优势**
7. **主流、主动、主升**

## 📊 评分系统标准 V2.0

### 涨停股评分（100 分）

```
├── 连板高度 (40 分)
│   ≥4 连板=40 分，3 连板=30 分，2 连板=20 分，首板=10 分
├── 封板质量 (30 分)
│   基础分 (15 分)：开板 0 次=15 分，1 次=12 分，2 次=9 分，≥3 次=6 分
│   加分项 (15 分)：封成比>3=15 分，1-3=10 分，0.5-1=5 分，<0.5=0 分
├── 换手健康 (15 分)
│   3%-25%=15 分，25%-50%=10 分，<3%=8 分，>50%=5 分
└── 成交金额 (15 分)
    1 亿-50 亿=15 分，50-100 亿=12 分，>100 亿=8 分，<1 亿=5 分
```

### 核心池评分（140 分）

```
基础分 (60 分) ← 技术面
├── 连板高度 (20 分)
├── 封板质量 (20 分)
├── 换手健康 (10 分)
└── 成交金额 (10 分)

加分项 (40 分) ← 情绪面 + 题材面 + 人气面
├── 情绪周期 (0-15 分)
│   启动期=15 分，发酵期=12 分，高潮期=8 分，退潮期=0 分
├── 主线题材 (0-15 分)
│   国家级政策=15 分，部委级=12 分，行业=10 分，个股=5 分，无=0 分
└── 人气辨识度 (0-10 分)
    市场总龙头=10 分，板块龙头=8 分，人气股=5 分，跟风=0 分
```

## 💡 开发指导原则

1. **数据驱动**：所有判断基于客观数据（K线、成交量、换手率、MACD等）
2. **情绪优先**：市场情绪 > 技术形态 > 基本面
3. **趋势为王**：顺势而为，不猜顶底
4. **风控第一**：仓位管理 > 选股能力
5. **简单有效**：复杂的不一定好，能赚钱的才是好系统
