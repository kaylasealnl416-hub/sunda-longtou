## 🎯 开发目标

### 核心目标
**打造一个基于客观数据的龙头股识别系统，能够：**
1. 准确识别市场情绪周期
2. 锁定主线题材和强势个股
3. 提供仓位管理建议
4. 找到高胜率、高盈亏比的龙头股

### 设计原则
1. **情绪优先**：市场情绪 > 技术形态 > 基本面
2. **数据驱动**：所有判断基于客观数据
3. **简单有效**：能赚钱的才是好系统
4. **风控第一**：仓位管理 > 选股能力

## 📅 开发阶段

### 第一阶段：核心逻辑重构（3-5 天）

#### 1.1 情绪周期识别系统 ⭐⭐⭐
**目标：** 准确判断市场所处的情绪周期

**数据来源：**
- 涨停板数量（连板高度分布）
- 炸板率
- 成交量变化
- 9 大指数量比
- 大小盘风格

**输出：**
```python
{
  "stage": "启动期",  # 冰点/启动期/发酵期/高潮期/退潮期
  "confidence": 85,   # 置信度
  "position_advice": "60-80%",  # 仓位建议
  "signals": [
    "涨停板数量回升",
    "炸板率下降",
    "量比放大"
  ]
}
```

**判断标准：**
- **冰点期**：涨停板 < 20，炸板率 > 50%，量比 < 0.8
- **启动期**：涨停板 20-40，炸板率 30-50%，量比 0.8-1.2
- **发酵期**：涨停板 40-80，炸板率 20-30%，量比 1.2-1.8
- **高潮期**：涨停板 > 80，炸板率 < 20%，量比 > 1.8
- **退潮期**：涨停板下降，炸板率上升，量比回落

#### 1.2 量比评分系统重构 ⭐⭐⭐
**目标：** 量比成为核心指标（权重 30%）

**逻辑：**
```python
# 量比 < 0.5 + 创新高 = 主力控盘（加分）
if volume_ratio < 0.5 and is_new_high:
    score += 15
    
# 量比 > 1.5 + 上涨 = 放量进攻（加分）
if volume_ratio > 1.5 and price_change > 0:
    score += 12
    
# 量比 0.8-1.2 = 正常（中性）
if 0.8 <= volume_ratio <= 1.2:
    score += 8
```

#### 1.3 主流题材识别 ⭐⭐
**目标：** 识别当前主线题材

**数据来源：**
- 板块涨幅排行
- 板块涨停股数量
- 板块持续天数
- 政策新闻

**输出：**
```python
{
  "main_theme": "AI算力",
  "level": "国家级",  # 国家级/部委级/行业/个股
  "score": 15,
  "related_stocks": ["002261", "600410"],
  "持续天数": 3
}
```

#### 1.4 评分系统 V3.0 ⭐⭐⭐
**新评分逻辑：**

```
总分 = 情绪面(30%) + 资金面(30%) + 技术面(25%) + 题材面(15%)

情绪面 (30 分)：
  - 情绪周期得分 (15 分)
  - 量比得分 (15 分)

资金面 (30 分)：
  - 资金净流入 (15 分)
  - 大单占比 (15 分)

技术面 (25 分)：
  - 连板高度 (10 分)
  - 封板质量 (8 分)
  - 趋势得分 (7 分)

题材面 (15 分)：
  - 主线题材 (10 分)
  - 人气辨识度 (5 分)
```
