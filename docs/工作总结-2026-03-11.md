## 💡 核心理解（最重要的收获）

### 1. 一套评分系统，不是三套
```
所有股票用同一套评分标准
但根据实际表现得分不同
不是给不同股票设计不同系统
```

### 2. 情绪周期是基础
```
情绪周期判断准确
    ↓
对应不同的评分策略
    ↓
选出符合当前阶段的股票
    ↓
配合仓位管理
    ↓
实现高胜率
```

### 3. 动态评分，不是固定分数
```
同一只股票，不同周期，不同分数
同一个指标，不同环境，不同含义

例如：4连板股票
- 冰点期：6分（风险）
- 启动期：10分（正常）
- 发酵期：14分（加分）
- 高潮期：8分（减分）
- 退潮期：3分（陷阱）
```

### 4. 顺势而为
```
大盘风格 → 大盘股加分
小盘风格 → 小盘股加分
主流题材 → 相关股加分
跟着资金走，不猜顶底
```

## 📊 评分系统设计

### 权重分配
```
情绪面 30%（最重要）
├─ 情绪周期 15%
└─ 量比 15%

技术面 30%（重要）
├─ 连板高度 12%
├─ 封板质量 10%
└─ 趋势 8%

资金面 25%（很重要）
├─ 资金净流入 15%
└─ 大单占比 10%

题材面 10%（重要）
├─ 主线题材 6%
└─ 人气热度 4%

基本面 5%（次要）
├─ 业绩连续性 3%
└─ 业绩增长 2%
```

### 动态调整
```
市场风格调整：±5分
换手率调整：±3分
情绪周期影响：动态策略
```

## 🎯 五种评分策略

### 冰点期 - 抄底策略
- 首板加分（+2分）
- 超跌股加分
- 缩量加分
- 高连板减分（-3分）
- 仓位：10-20%

### 启动期 - 追涨策略
- 2-3连板加分（+2分）
- 放量突破加分
- 主流题材加分
- 创新高加分
- 仓位：40-60%

### 发酵期 - 持有策略
- 3-4连板加分（+2分）
- 充分换手加分（+3分）
- 上升趋势加分
- 板块龙头加分
- 仓位：60-80%

### 高潮期 - 减仓策略
- 高连板减分（-2分）
- 放量减分（-2分）
- 低连板加分
- 新启动加分
- 仓位：40-60%

### 退潮期 - 空仓策略
- 所有连板减分（-3分）
- 现金为王
- 只看不动
- 仓位：20-30%
