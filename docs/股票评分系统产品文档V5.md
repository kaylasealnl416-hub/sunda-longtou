## 一、系统概述

### 1.1 产品定位
量化选股工具，通过多维度评分筛选强势龙头股，帮助投资者在首板后追踪潜力标的。

### 1.2 核心策略
- **首板筛选**: 只评分出现首板的股票
- **3日追踪**: 首板后追踪3天，判断是否能继续涨停
- **评分对比**: 每次首板评分对比，动态调整优选股

### 1.3 适用场景
- 短线交易者寻找龙头股
- 打板族优化选股策略
- 量化交易策略研发

## 二、评分体系详解

### 2.1 三层评分结构

评分采用**加权综合评分**，总分100分满分：

```
综合分 = 市场层(15分) + 板块层(30分) + 个股层(55分)
```

**为什么这样分配？**
- 市场层(15%): 大环境决定仓位
- 板块层(30%): 板块强度决定弹性
- 个股层(55%): 个股质量决定涨幅

---

### 2.2 市场层评分 (15分)

市场层反映大盘整体环境，大环境好时成功率更高。

#### 2.2.1 涨跌家数比 (权重: 10%)

**计算公式**: `得分 = 上涨家数 / 总家数 × 50`

| 市场状态 | 上涨比例 | 得分 |
|----------|----------|------|
| 普涨 | >60% | 30分 |
| 偏涨 | 50%-60% | 25分 |
| 震荡 | 40%-50% | 20分 |
| 偏跌 | 30%-40% | 15分 |
| 普跌 | <30% | 10分 |

#### 2.2.2 涨停数 (权重: 10%)

**计算公式**: `得分 = min(涨停数 ÷ 3 × 10, 30分)`

| 涨停数 | 得分 |
|--------|------|
| ≥100家 | 30分 |
| 50-100家 | 20分 |
| 20-50家 | 15分 |
| <20家 | 10分 |

#### 2.2.3 跌停数 (权重: 8%)

**计算公式**: `得分 = max(100 - 跌停数×5, 20分)`

| 跌停数 | 得分 |
|--------|------|
| 0家 | 25分 |
| 1-5家 | 20分 |
| 6-10家 | 15分 |
| >10家 | 10分 |

#### 2.2.4 量能 (权重: 8%)

**计算公式**: 
- 成交量 > 1.0万亿 → 20分
- 成交量 0.8-1.0万亿 → 15分
- 成交量 < 0.8万亿 → 10分

#### 2.2.5 封板率 (权重: 6%)

**计算公式**: `得分 = 封板率数值` (如70%封板率=7分)

| 封板率 | 得分 |
|--------|------|
| >80% | 8分 |
| 60%-80% | 6分 |
| <60% | 4分 |

#### 2.2.6 市场系数

根据市场状态，应用不同的系数：

| 市场状态 | 系数 | 说明 | 操作建议 |
|----------|------|------|----------|
| 主升 | 1.2 | 上升趋势中 | 积极做多 |
| 发酵 | 1.1 | 热点扩散中 | 把握主线 |
| 冰点 | 1.0 | 情绪低谷 | 可试错 |
| 震荡 | 0.9 | 方向不明 | 谨慎 |
| 退潮 | 0.7 | 风险释放 | 减少操作 |
| 高潮 | 0.8 | 风险累积 | 逢高减仓 |

**最终市场层得分**:
```
市场层总分 = (涨跌家数比 + 涨停数 + 跌停数 + 量能 + 封板率) × 市场系数
```

## 三、首板追踪机制

### 3.1 追踪流程

```
首板出现 → 首次评分 → 追踪3天
     │
     ├── 3天内又涨停 → 继续追踪(+分)
     │
     └── 3天不涨停 → 放弃追踪(可重新首板)
```

### 3.2 追踪状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 追踪中 | tracking | 首板后3天内 |
| 放弃 | dropped | 3天未涨停 |
| 重新首板 | reset | 再次出现首板 |
| 成功 | success | 3天内继续涨停 |

### 3.3 评分对比机制

当股票再次出现首板时，对比两次评分：

| 情况 | 记分 | 说明 |
|------|------|------|
| 评分更高 | +正分 | 如 85-72=+13 |
| 评分更低 | +负分 | 如 68-72=-4 |
| 评分相近 | +0分 | 差异<5分 |

**加分公式**: `本次评分 - 上次评分`

### 3.4 追踪加分

- 第二天继续涨停: +10分
- 第三天继续涨停: +15分
- 第四次涨停: +20分
