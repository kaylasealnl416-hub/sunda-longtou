## 一、系统概述

量化选股工具，通过多维度评分筛选强势龙头股

### 1.2 核心策略
- **首板筛选**：只评分出现首板的股票

### 1.3 产品优势

- 多维度评分（27个因子）

## 二、评分体系

### 2.1 三层评分结构

```
综合分 = 市场层(15%) + 板块层(30%) + 个股层(55%)
```

### 2.2 市场层评分 (15%)

| 指标 | 权重 | 评分规则 |
|------|------|----------|
| 涨跌家数比 | 10% | 上涨家数/总家数 × 50 |
| 涨停数 | 10% | 涨停数 ÷ 3 × 10 |
| 跌停数 | 8% | (100 - 跌停数×5) |
| 量能 | 8% | 量能>1.0得20分 |
| 封板率 | 6% | 封板率数值 |

**市场系数：**
| 市场状态 | 系数 | 说明 |
|----------|------|------|
| 主升 | 1.2 | 最佳 |
| 发酵 | 1.1 | 较好 |
| 冰点 | 1.0 | 可试错 |
| 震荡 | 0.9 | 中性 |
| 退潮 | 0.7 | 风险 |
| 高潮 | 0.8 | 风险大 |

### 2.3 板块层评分 (30%)

| 指标 | 权重 | 评分规则 |
|------|------|----------|
| 板块涨幅 | 10% | 涨幅 × 2 |
| 涨停家数 | 12% | 涨停数 × 5 |
| 资金流入 | 10% | 净流入 × 0.5 |
| 助攻数量 | 8% | 跟风涨停数 × 5 |

**板块动量：**

| 电力 | +0.15 |
| 油气 | +0.10 |

### 2.4 个股层评分 (55%)

## 三、首板追踪机制

### 3.1 追踪流程

```
首板出现 → 开始评分 → 追踪3天
     │
     ├── 3天内又涨停 → 继续追踪(+分)
     │
     └── 3天不涨停 → 放弃追踪
```

### 3.2 评分对比

- 第二次首板：对比上次评分
  - 评分更低 → 记负分 (如 68-72 = -4)
  - 评分更高 → 记正分 (如 80-72 = +8)

### 3.3 状态管理

| 状态 | 说明 |
|------|------|
| 追踪中 | 首次出现首板，正在追踪 |
|3天不涨停 放弃 | ，停止追踪 |
| 重新首板 | 再次出现首板，重新评分 |

## 五、评分计算示例

### 5.1 示例：顺钠股份

**基础数据：**
- 连板数：5板
- 板块：电力
- 量化：是
- 小盘：是
- 题材数：3

**计算：**
```
基础分 = 70
连板分 = 5 × 12 = 60
量化分 = 25
小盘分 = 20
题材分 = 3 × 5 = 15
板块分 = 90 × 0.3 = 27
额外(5板+) = 10

原始分 = 70+60+25+20+15+27+10 = 227

市场系数(主升) = 1.2
板块系数(电力) = 1.15

最终分 = 227 × 1.2 × 1.15 ≈ 313分
```
