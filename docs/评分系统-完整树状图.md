## 📊 详细评分标准

### 一、情绪面（30分）⭐⭐⭐

**为什么最重要？**
- 小欧说："炒股炒的是预期，不是现在"
- 市场情绪决定资金流向
- 情绪周期决定买卖时机

#### 1.1 情绪周期（15分）

**评分标准：**
```
冰点期 → 15分 (抄底机会，最高分)
├─ 特征：涨停板<20，炸板率>50%，量比<0.8
├─ 逻辑：市场极度悲观，是最佳买入时机
└─ 仓位建议：10-20%

启动期 → 12分 (追启动初期)
├─ 特征：涨停板20-40，炸板率30-50%，量比0.8-1.2
├─ 逻辑：市场开始回暖，确定性最高
└─ 仓位建议：40-60%

发酵期 → 10分 (主升浪持有)
├─ 特征：涨停板40-80，炸板率20-30%，量比1.2-1.8
├─ 逻辑：市场情绪高涨，主升浪阶段
└─ 仓位建议：60-80%

高潮期 → 6分 (准备减仓)
├─ 特征：涨停板>80，炸板率<20%，量比>1.8
├─ 逻辑：市场过热，风险增加
└─ 仓位建议：40-60%

退潮期 → 3分 (杀下跌之际)
├─ 特征：涨停板下降，炸板率上升，量比回落
├─ 逻辑：市场转弱，及时止损
└─ 仓位建议：20-30%
```

**核心思想：**
- 冰点期得分最高（逆向思维）
- 追启动初期，不追高潮期
- 情绪周期直接对应仓位

---

#### 1.2 量比（15分）⭐⭐⭐ 核心指标

**为什么是核心？**
- 小欧说："量比是核心指标（权重30%）"
- 量比反映主力意图
- 缩量创新高 = 主力控盘

**评分标准：**
```
缩量创新高 (量比<0.5 + 20日新高) → 15分
├─ 逻辑：没人卖，少量资金就能拉涨
├─ 结论：主力高度控盘
└─ 信号：强烈看多

放量突破 (量比>1.5 + 涨幅>5% + 突破阻力位) → 13分
├─ 逻辑：主力进攻，突破关键位置
├─ 结论：启动信号
└─ 信号：强烈看多

放量上涨 (量比>1.5 + 涨幅0-5%) → 11分
├─ 逻辑：资金活跃，承接力强
├─ 结论：上涨趋势
└─ 信号：看多

量比正常 + 上涨 (量比0.8-1.2 + 涨幅>0) → 9分
├─ 逻辑：温和上涨，稳健
├─ 结论：正常走势
└─ 信号：中性偏多

量比正常 + 下跌 (量比0.8-1.2 + 涨幅<0) → 6分
├─ 逻辑：温和下跌
├─ 结论：观望
└─ 信号：中性

缩量下跌 (量比<0.8 + 涨幅<0) → 7分
├─ 逻辑：可能是洗盘，不是出货
├─ 结论：等待机会
└─ 信号：观望

放量下跌 (量比>1.5 + 涨幅<-3%) → 3分
├─ 逻辑：主力出货
├─ 结论：风险信号
└─ 信号：看空

量比异常 (量比>3) → 5分
├─ 逻辑：过度放量，警惕风险
├─ 结论：观察
└─ 信号：警惕
```

**动态调整（根据情绪周期）：**
```
冰点期/启动期：
- 缩量 → 加分（惜售是好事）
- 放量 → 正常

高潮期/退潮期：
- 缩量 → 正常
- 放量 → 减分（可能出货）
```

### 二、资金面（25分）⭐⭐⭐

**为什么很重要？**
- 资金是市场的血液
- 资金流向决定股价走势
- 大单占比反映主力动向

#### 2.1 资金净流入（15分）

**评分标准：**
```
超大单净流入 (>5000万) → 15分
├─ 逻辑：主力大举买入
└─ 信号：强烈看多

大单净流入 (1000万-5000万) → 12分
├─ 逻辑：资金持续流入
└─ 信号：看多

中单净流入 (0-1000万) → 9分
├─ 逻辑：散户跟风
└─ 信号：中性偏多

小幅流出 (-1000万-0) → 6分
├─ 逻辑：正常波动
└─ 信号：中性

大幅流出 (<-1000万) → 3分
├─ 逻辑：资金撤离
└─ 信号：看空
```

---

#### 2.2 大单占比（10分）

**评分标准：**
```
大单占比>60% → 10分
├─ 逻辑：主力主导
└─ 信号：强势

大单占比40-60% → 8分
├─ 逻辑：主力参与
└─ 信号：正常

大单占比30-40% → 6分
├─ 逻辑：散户为主
└─ 信号：一般

大单占比<30% → 4分
├─ 逻辑：缺乏主力
└─ 信号：弱势
```

### 三、技术面（30分）⭐⭐

**为什么重要？**
- 技术面反映市场行为
- 连板高度反映强度
- 趋势是你的朋友

#### 3.1 连板高度（12分）

**评分标准：**
```
≥4连板 → 12分
├─ 逻辑：超强势，市场总龙头
└─ 风险：高位注意回调

3连板 → 10分
├─ 逻辑：强势，板块龙头
└─ 风险：中等

2连板 → 8分
├─ 逻辑：较强势
└─ 风险：较低

首板 → 6分
├─ 逻辑：启动信号
└─ 风险：低

未涨停 → 按涨幅比例给分
├─ 涨幅>7% → 5分
├─ 涨幅5-7% → 4分
├─ 涨幅3-5% → 3分
├─ 涨幅0-3% → 2分
└─ 涨幅<0 → 0分
```

**动态调整（根据情绪周期）：**
```
冰点期：首板得分 +2分（启动信号）
启动期：2-3连板得分 +2分（确定性高）
发酵期：3-4连板得分 +2分（主升浪）
高潮期：≥4连板得分 -2分（风险）
退潮期：所有连板得分 -3分（风险）
```

---

#### 3.2 封板质量（10分）

**评分标准：**
```
一字板 (开板0次 + 封成比>10) → 动态评分
├─ 冰点期/启动期 → 10分 (主力控盘强)
├─ 发酵期 → 8分 (正常)
└─ 高潮期/退潮期 → 5分 (风险)

无开板 (开板0次) → 10分
├─ 逻辑：封板坚决
└─ 信号：强势

开板1次 → 8分
├─ 逻辑：有分歧但封住
└─ 信号：较强

开板2次 → 6分
├─ 逻辑：分歧较大
└─ 信号：一般

开板≥3次 → 4分
├─ 逻辑：封板不坚决
└─ 信号：弱势

未涨停 → 0分
```

**封成比加分：**
```
封成比>3 → +2分
封成比1-3 → +1分
封成比<1 → 0分
```

---

#### 3.3 趋势（8分）

**评分标准：**
```
站上4条均线 (5/10/20/60日) → 8分
├─ 逻辑：强势上升趋势
└─ 信号：持有

站上3条均线 → 6分
├─ 逻辑：上升趋势
└─ 信号：看多

站上2条均线 → 4分
├─ 逻辑：趋势不明
└─ 信号：观望

站上≤1条均线 → 2分
├─ 逻辑：下降趋势
└─ 信号：回避
```

**小欧说："上升趋势的股票不要出"**
- 站上4条均线 → 持有信号
- 不做T，拿住主升浪

**为什么重要？**
- 主流题材决定方向
- 资金聚焦的地方

#### 4.1 主线题材（6分）

**评分标准：**
```
国家级政策 → 6分
├─ 关键词：一带一路、国企改革、数字经济、新基建、碳中和
├─ 逻辑：政策支持力度最大
└─ 持续性：长期

部委级政策 → 5分
├─ 关键词：AI、芯片、新能源、光伏、储能
├─ 逻辑：行业政策支持
└─ 持续性：中期

行业热点 → 4分
├─ 关键词：游戏、医药、消费
├─ 逻辑：行业景气度
└─ 持续性：短期

个股题材 → 2分
├─ 关键词：重组、并购、业绩预增
├─ 逻辑：个股事件
└─ 持续性：极短期

无明确题材 → 0分
```

**主线题材加分：**
```
属于当日主线题材 → +2分
属于相关板块 → +1分
其他题材 → 0分
```

## 🔧 动态调整因子

### 1. 市场风格调整（±5分）

**大盘风格日：**
```
大盘股 (市值>500亿) → +5分
中盘股 (100-500亿) → 0分
小盘股 (<100亿) → -3分
```

**小盘风格日：**
```
小盘股 → +5分
中盘股 → 0分
大盘股 → -3分
```

**均衡风格日：**
```
所有股票 → 0分
```

**判断标准：**
```
上证50涨幅 - 中证1000涨幅 > 0.5% → 大盘风格
上证50涨幅 - 中证1000涨幅 < -0.5% → 小盘风格
其他 → 均衡风格
```

---

### 2. 换手率调整（±3分）

**根据情绪周期动态调整：**

**冰点期/启动期：**
```
换手<3% → +3分 (惜售，好事)
换手3-10% → +2分
换手>10% → 0分
```

**发酵期：**
```
换手5-15% → +3分 (充分换手，承接强)
换手<5% → +1分
换手>15% → 0分
```

**高潮期/退潮期：**
```
换手>20% → -2分 (出货风险)
换手10-20% → 0分
换手<10% → +2分
```

## 💡 核心思想总结

### 1. 权重分配逻辑

**情绪面 30% > 技术面 30% > 资金面 25% > 题材面 10% > 基本面 5%**

**为什么这样分配？**
- 情绪决定时机（什么时候买）
- 技术反映强度（买什么样的）
- 资金决定方向（资金往哪流）
- 题材决定持续性（能涨多久）
- 基本面最次要（炒的是预期）

### 2. 动态评分

**不是固定分数，而是根据：**
- 情绪周期
- 市场风格
- 换手率
- 板块热度

**同一个现象，不同环境，不同分数**

### 3. 顺势而为

**核心：跟着资金走，不猜顶底**
- 大盘风格 → 大盘股加分
- 小盘风格 → 小盘股加分
- 主流题材 → 相关股加分
- 情绪周期 → 对应仓位
